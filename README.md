# Crash Circuit

Protótipo web 3D de um jogo arcade de colisões, criado com Babylon.js, Havok, TypeScript e Vite.

## Executar

```bash
npm install
npm run dev
```

Abra a URL exibida pelo Vite. Use `WASD` ou as setas para dirigir e `R` para reiniciar.

## Verificar

```bash
npm run check
```
